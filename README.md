# Esfera

## Descrição
O projeto Esfera visa criar um modelo-simulação física de um sistema "pêndulo simples" cujo controle está na ponta do pendulo, no seu centro de massa. O controle é feito em 3 graus de liberdade com 3 motores + hélices tangentes ao raio da esfera, fixas à esfera.

## Pré-requisitos
- Python 3.x
- Node.js (se necessário)

## Instruções de Instalação/Execução
1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-repositorio/esfera.git
   cd esfera
   ```

2. Crie e ative um ambiente virtual (Python):
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # No Windows
   # ou
   source .venv/bin/activate  # No Linux/Mac
   ```

3. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

4. Execute o projeto:
   ```bash
   python main.py
   ```
